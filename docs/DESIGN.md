# DESIGN · 在途（ZAITU）

## 0. 愿景和边界
在途是由独立生活插件组成的个人生活操作系统，目标是实现「记录 → 理解 → 用户确认 → 行动 → 反馈 → 调整」的迭代闭环。产品不是只展示工具卡片的导航站，也不是全自动替用户作决定的 Agent。用户拥有数据、选择权和最终控制权。

## 1. 用户路径
- 首页「旅途」：今日问候、可用插件、最近足迹、AI 入口。
- 「行囊」插件中心：发现、启停、进入插件及查看能力/权限。
- 「足迹」：按时间倒序查看个人事件。MVP 使用浏览器本地存储。
- AI 旅伴：与用户沟通，由用户明确同意后才在插件之间流转敏感信息。
- 「路标」目标规划：后续版本以用户定义、可测量指标为基础，不编造进度。

## 2. 主项目与子项目所有权
### Platform Team
`apps/web` 外壳、路由、导航、首页、插件中心、深色模式、AI 面板；`apps/api` DeepSeek 网关；`packages/core` 注册表、权限闸门、事件流、生命周期；`packages/plugin-sdk` 插件标准接口；`packages/design-system` 颜色/间距/卡片/字号/无障碍；CI 与安全。
### Plugin Teams
每个 `plugins/<id>` 独立维护视图、业务算法、持久化键、测试、插件文档。插件不能修改全局主题或读取别的插件私有数据；跨插件数据需经过 Core 和授权。共享样式必须通过设计系统扩展，不得自己重新定义导航/主题基础变量。

| 插件目录 | 名称 | 首期范围 | 后续范围 |
|---|---|---|---|
| mood | 心晴 | 七种情绪、今日日志、本地事件 | 日历、连续记录、统计 |
| meal | 食光 | 偏好输入、AI 饮食建议 | 图片输入、餐厅、计划 |
| nutrition | 生命刻度 | 常见食物营养示例 | 来源可信的营养数据库 |
| leisure | 摸鱼湾 | 放松抽签、小工具入口 | 模块化游戏与老板键 |
| reading | 知行 | 阅读评价输入、AI 辅助 | 章节解析、阅读清单 |
| fire | 自由航线 | 可解释的基础 FIRE 计算 | 账单解析、情景模拟 |

## 3. 统一交互语言
品牌「在途」，调性安静、松弛、自然，偏旅行手账而非高饱和游戏大厅。统一导航、12 列响应网格、白/深色模式、圆角和柔和阴影。插件允许独立强调色，但背景、字号、弹窗和表单来自设计系统。所有用户操作应有加载、失败、空状态。动画必须尊重 prefers-reduced-motion。

## 4. 信息与安全
- 个人记录默认 local-first；MVP 仅浏览器本机，不同步、不承诺跨设备可用。
- API key 只放根目录 .env、只在 apps/api 服务端被读取；严禁经 Vite import.meta.env 暴露。
- AI 发送资料前需可见提示；跨插件读取改为显式权限授权后再正式上线。当前 MVP 是内部可信模块架构，不提供第三方任意代码插件。
- 健康建议不用单餐预测真实寿命；投资使用情景模拟、显示假设和风险。
- 公开部署前增加鉴权、速率限制、预算配额、敏感数据删除和审计记录。

## 5. 非目标（MVP）
不开发动态远程安装的第三方插件、不上传财务/健康资料到云端、不做生产环境用户账号/支付、不宣称医疗效果和真实退休预测。
