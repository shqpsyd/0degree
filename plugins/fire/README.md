# 自由航线 · FIRE

Owner: FIRE Team。提供可解释的基础资产目标计算，不等于退休保障或投资收益承诺。

## 使用

在插件中心启用「自由航线」，进入 `#/plugins/zaitu.fire`。

1. 输入期望月支出、可投资净资产和初始年度提款率，查看即时计算结果。
2. 查看 3%、4%、5% 提款率的静态对照，可采用其中一组假设继续调整。
3. 点击「保存本机方案」，下次进入时恢复；「填入示例」只修改当前输入，需保存才会覆盖旧方案。

目标资产 = 月支出 × 12 ÷（提款率 ÷ 100）；缺口最低为零；覆盖比例可超过 100%，进度条最高展示 100%。零支出时目标为零、覆盖比例不适用。金额展示四舍五入至元，中间计算不取整。空值、负值、非有限值和超范围输入不会用于计算或保存。月支出上限 10 亿元、资产上限 1 万亿元，非零金额最低 0.01 元，提款率范围 0.1%–20%；这些是输入边界，不是合理性或安全性建议。

模型不包含通胀、税费、投资波动、收益顺序风险、未来收入和退休年限。不提供退休日期预测、账单导入或投资推荐。

## 数据与权限

- 保持 `permissions: []`，不调用 AI、不写足迹、不发网络请求。
- 使用宿主 `context.storage` 的逻辑键 `plan.v1`，数据形状为 `{ version: 1, monthlyCost, assets, rate }`。
- 仅显式保存一份本机方案；写入失败显示错误并保留输入，支持重试。
- 无旧存储需要迁移。无效形状或未知版本回退示例，不自动覆盖旧数据；宿主对 JSON 损坏或读取失败返回默认值，插件无法区分其与首次使用。
- 清理插件数据会移除方案。平台足迹导出不包含本插件的私有数据，不支持跨设备同步。

## 视觉与验证

复用平台 `card`、`field`、`btn`、`notice` 等样式与主题 token；局部样式以 `fire-` 为前缀。宽屏双栏，760px 以下单栏；使用真实标签、错误关联、状态播报和键盘可操作的原生控件。

在仓库根目录执行：

```sh
npm test -- plugins/fire
npm run typecheck
npm run build
```
