# 生命刻度 · nutrition

本期交付 P1-04「营养结构与来源提示」。沿用宿主设计 token、按钮、输入框、通知及卡片；插件样式均以 `nutrition-` 为前缀，支持亮暗主题、窄屏单列与键盘操作。

## 使用

- 浏览苹果、鸡蛋、西兰花、米饭、牛奶、鸡胸肉六种示例，按名称搜索或按分类筛选。
- 查看食物的生熟状态及每 100 克可食部的能量、蛋白质、脂肪、碳水化合物、膳食纤维。
- 输入 1–2000 克的重量（可含小数），或选用 50/100/200 克快捷重量。当前份量按比例换算，显示最多一位小数；无效重量不计算、不保存。
- 点击「保存本机选择」保存当前食物和重量。写入失败保留当前输入并提示重试，重新打开时恢复有效数据；无效或无法读取的记录回退到苹果 100 克，不自动覆盖原数据。

## 数据与来源边界

`src/model.ts` 中的 `FOODS` 是版本 `demo-v1` 的项目内置演示数据，**尚未接入或逐项核验权威食物成分数据库**。每种食物详情均展示这一来源状态，不把示例写成检测值、品牌标签或真实健康结果。食物状态属于示例定义，不是生食建议；实际数值随品种、加工及含水量变化。

计算公式为「每 100 克数值 × 可食部重量 ÷ 100」。内部计算不提前舍入；膳食纤维与碳水化合物不能简单相加。本模块不计算饮食健康评分、推荐摄入量、医疗效果或单餐导致的真实寿命变化。可信数据库接入属于后续工作。

## 存储与权限

使用宿主 `context.storage`，逻辑键 `selection.v1`：

```json
{ "version": 1, "foodId": "apple", "grams": 100 }
```

宿主完整键为 `zaitu.plugin.zaitu.nutrition.selection.v1`。仅当前浏览器保存一份选择；搜索词和分类不持久化，不记录摄入历史，不同步、不随足迹导出。宿主清理插件数据会删除此记录。

`permissions: []`。不调用 AI、不发布或读取足迹、不发送网络请求。没有数据发送给模型或其他外部服务。

## 验证

在仓库根目录运行：

```sh
npm test -- plugins/nutrition
npm run typecheck
npm run build
```

测试覆盖份量换算、边界与无效输入、持久化恢复/损坏回退、筛选空态、保存失败重试。浏览器验收：亮暗主题与 375px 窄屏；键盘筛选与输入；插件打开/切换/禁用；保存后重开、清理数据后重开。
