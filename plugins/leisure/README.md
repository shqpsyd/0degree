# 摸鱼湾 · Leisure

首期提供放松抽签与本地小工具，保持在途安静、自然的旅行手账风格。

## 使用

- 放松签：内置六条日常休息建议，点击“换一张放松签”不会连续抽到同一条。
- 休息计时器：选择 1 / 2 / 5 分钟，可开始、暂停、继续和重置。切换时长会重置计时。到时仅显示文字，不请求通知权限、不播放声音。
- 随心选一个：每行填写一个选项，支持 2–12 个不同选项，每项最多 40 字；忽略空行与重复项。修改输入会清除旧结果，再次抽取避开上次结果。
- 同时只打开一个工具；收起、切换、离开或禁用插件会卸载工具，清理计时器与事件监听。浏览器后台可能延迟刷新，返回时按截止时间校准。

## 模块扩展

`src/registry.ts` 定义 `LeisureModule` 与 `registerModules`。工具或后续小游戏各自放在 `src/modules/`，在 `src/modules/index.ts` 静态注册唯一的短 ID、名称、说明、图标和 React 组件。非法或重复 ID 会在注册时失败。

组件接收宿主的 `PluginContext`；组件内的定时器、监听和其他资源必须由 `useEffect` 返回清理函数。切换模块通过 React key 卸载旧实例。不支持远程脚本加载；老板键、游戏与跨插件情绪建议不在本次首期范围内。

## 权限与数据

`permissions: []`，不调用 AI、不读取或写入足迹，不申请额外权限。全部状态仅存于组件内存，刷新或离开后重置；不使用持久化键，没有历史数据迁移。选择输入不会上传或保存。

## 视觉与无障碍

复用设计系统 `card`、`btn`、`notice`、`field` 和主题 token；局部样式统一 `leisure-` 前缀。宽屏双栏，760px 以下单栏，兼容亮/暗主题。不引入动画；原生按钮支持键盘，输入提供 label 与错误关联，抽签和完成提示使用状态播报，倒计时不逐秒打断读屏。

## 验证

```sh
npm test -- plugins/leisure
npm run typecheck
npm run build
```

自动测试覆盖随机抽取边界、选项处理、模块注册、计时暂停/恢复/完成与卸载清理。手工验收：375px 窄屏、亮/暗主题、键盘焦点、切换工具重置、后台返回校准。计时器没有系统通知，关闭页面后不会提醒。
