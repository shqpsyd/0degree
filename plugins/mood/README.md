# 心晴 mood

七种天气记录当下心情，提供今日日志、月历回看、连续记录天数与按月天气分布。沿用主站设计 token、表单与按钮样式，支持亮暗主题、键盘单选与窄屏布局。

## 使用

在插件中心打开「心晴」，选择天气，选填最多 2000 字的复盘，点击保存。保存失败会保留输入并允许重试。当天已有记录时自动填入最后一条；内容未改变时禁用重复保存。改变天气或文字后可再次保存，足迹保留每次记录，月历与统计每天仅计算最后一条。

月历可切换月份，点击日期查看当日最后一次天气和复盘。连续天数从今天开始；今天未记录时从昨天开始计算。没有记录时展示空态，不生成演示数据，不将天气转换为心理健康评分。

## 数据与权限

- `timeline.write`：发布 `mood.logged`，字段沿用 `{ mood: "晴·开心", note: "…" }`。
- 新增 `timeline.read`：通过 Core 读取足迹，仅使用 `source === "zaitu.mood"` 且 `type === "mood.logged"` 的有效事件。SDK 当前仅检查权限声明，没有用户授权弹窗。
- 无 AI 调用、网络请求或独立存储副本。足迹为唯一数据源，历史删除后重新打开插件即反映删除结果。
- 兼容原版事件，无需迁移。日期由 `occurredAt` 按当前设备本地时区计算，更换时区可能改变日期归属。未知天气或无效时间戳不参与统计。
- 数据仅保存在当前浏览器；平台最多保留最近 500 条所有插件的足迹，因此统计不是永久完整历史。复盘会随足迹导出。

## 验证

在仓库根目录运行：

```sh
npm test -- plugins/mood
npm run typecheck
npm run build
```

自动测试覆盖事件过滤、旧数据兼容、日内去重、跨月连续记录、闰年月历、七种情绪保存、失败重试与历史读取失败。视觉人工验收：亮/暗主题、375px 宽度、键盘切换天气及月历；当前未附浏览器截图。
